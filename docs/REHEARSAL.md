# 리허설 기록

연습(리허설)에서 발견한 운영 문제와 해결 방법을 적는다.

## 2026-09-28 부스 라운드 첫 연습

### 학생 화면이 진행되지 않음

- 상황: 새 버전을 배포하고 1분 뒤에 연습을 시작했다. 교사가 골든벨 부스에서 라운드를 열고 게임을 시작했는데 학생 기기(4학년 1반 1팀)의 화면이 바뀌지 않았다.
- 확인: 배포된 사이트를 새 기기에서 열면 같은 팀 화면이 정상이었다(게임 중, 남은 시간, 시간이 끝나면 저절로 제출 닫힘).
- 원인: 사이트 첫 화면(index.html)이 기기에 최대 1시간 저장되어, 배포 전에 열어 둔 기기는 옛 프로그램으로 돌아갔다.
- 해결: `firebase.json`에서 화면 주소의 응답을 `Cache-Control: no-cache`로 바꿨다. 기기는 열 때마다 새 버전이 있는지 확인한다. 이름에 해시가 붙는 `/assets/` 파일은 그대로 오래 저장한다.
- 운영 요령: 배포한 뒤에 열려 있던 탭은 한 번 새로고침한다. 행사 당일에는 배포하지 않는다.

### 입장이 교사 화면에 반영되지 않는 것처럼 보임

- 원인 1: 9월 17일 연습에서 교사가 직접 입장 처리한 기록이 남아 있어, 같은 팀이 처음부터 “입장 완료”로 보였다.
- 원인 2: 학생 홈의 “미션 시작”은 미션 화면을 여는 버튼이고 입장 기록이 아니다. 입장은 교사가 라운드를 연 뒤 교실 QR을 찍거나 교사 화면의 “입장 처리”를 눌러야 기록된다.
- 해결: 총괄의 행사 설정에 “연습 기록 지우기”를 만들었다. 학년을 고르면 남은 기록 수를 보여 주고, 확인 창에 학년을 적으면 그 학년의 기록을 지운다.

### 예전 연습 기록 때문에 생긴 다른 증상

- 골든벨 4학년 1라운드의 “정답 공개”가 켜진 채 남아 학생 화면에 정답이 보였다.
- 그리기 부스 4학년 1라운드는 9월 17일에 시작한 기록이 남아 “순위 매기는 중”으로 보였다.
- 해결: 행사 전에 학년마다 “연습 기록 지우기”를 한다.

## 2026-09-28 두 번째 연습(기록을 지운 뒤)

### 2번 미션 QR을 찍었더니 1번 미션 교실이 나옴

- 상황: 골든벨(1번) 부스에서 1라운드 순위를 확정하고 “1라운드 종료”는 누르지 않았다. 그 팀이 컴퓨터실(2번) QR을 찍자 “이미 입장했어요 · 1라운드 시청각실”이 나왔다.
- 확인: 교실 QR 다섯 장을 해독기로 읽으면 저마다 자기 교실의 주소가 나온다(테스트로 고정). QR은 맞다.
- 원인: 순위가 나온 팀이 QR을 찍으면 어느 교실 QR이든 “이미 입장했어요”로 안내하는 오류였다. 팀은 선생님이 라운드를 종료해야 다음 라운드로 넘어가므로 아직 1라운드에 있었다.
- 해결: 이 경우 “조금만 기다려요. ○○ 선생님이 N라운드를 종료하면 다음 교실에 들어갈 수 있어요”라고 안내하고 다음 교실을 알려 준다. 잘못 찍은 기록은 남기지 않는다.
- 교사 화면: 순위표 아래에 “N라운드 종료를 눌러야 팀이 다음 교실에 들어갈 수 있어요”와 이동 버튼을 둔다.

### 미션 화면을 열면 입장한 것처럼 보임

- 원인: 학생 홈의 버튼 이름이 “미션 시작”이라 누르면 입장되는 것으로 보였다. 입장은 교실 QR을 찍거나 교사가 “입장 처리”를 눌러야 기록된다.
- 해결: 입장 전에는 버튼 이름을 “미션 미리 보기”로 바꾸고, 팀 홈과 미션 화면에 “교실 입구의 QR을 디벗 카메라로 찍어야 입장돼요”를 보여 준다. 입장하면 “미션 시작”으로 바뀐다.

### 순위를 일찍 확정해도 타이머가 계속 흐름

- 해결: 순위를 확정한 때 게임이 끝난 것으로 보고 타이머를 “시간 종료”로 멈춘다.

### 라운드 순서에 대한 결정

- 1라운드를 끝내야 2라운드를 열 수 있는 순서대로 진행은 그대로 둔다. 행사 때는 다섯 부스가 같은 라운드를 함께 돌기 때문이다.
- 혼자 연습하거나 시간이 모자랄 때를 위해 “라운드 건너뛰기”를 만들었다. 게임과 순위 없이 라운드를 끝낸다.
- 앞 교실 선생님이 “라운드 종료”를 깜빡해도, 순위가 나온 팀은 다음 교실이 라운드를 열었으면 입장할 수 있게 했다.

## 2026-09-30 세 번째 연습 뒤 고친 것

### 게임을 시작하기 전에 문제가 보임

- 상황: 미션 화면을 열기만 하면 골든벨 문항, 그림 프롬프트, 도서관 지문, 로봇 규칙이 보였다(틀린그림 찾기만 가려져 있었다).
- 해결: 다섯 미션 모두 선생님이 “게임 시작”을 누르기 전(라운드 열기 전, 입장 중, 미리 보기, 다른 학년 시간)에는 문제 대신 가림막을 보여 준다. 문제 글은 화면에 올리지도 않는다. 시간이 끝난 미션은 보여 준다.

### 교실마다 QR을 찍는 것이 번거로움

- 결정: QR은 반·팀 등록(팀 입장)에만 쓴다. 교실 입장은 미션 화면에서 그 교실의 **인증코드(숫자 4자리)**를 넣는 방식으로 바꿨다. 코드는 교실마다 하나이고 라운드마다 같다.
- 총괄: 행사 설정 → 교실 인증코드에서 정한다(무작위로 만들기 가능). 행사 구조를 만들 때 없는 코드는 자동으로 채워진다. 인쇄 화면에서 교실 안에 붙일 안내문을 뽑을 수 있다.
- 부스: 부스 화면 위쪽에 자기 교실 코드가 크게 보인다. 라운드를 열면 들어온 팀에게 알려 준다. 코드를 넣지 못한 팀은 그대로 “입장 처리”로 기록한다.
- 학생: 팀 홈의 “인증코드 넣고 입장”을 누르면 미션 화면 위에 입력 칸이 나온다. 라운드를 열기 전에는 입력 칸이 없다. 세 번 틀리면 10초 뒤에 다시 넣을 수 있다.
- 보안: 코드는 교사만 읽는 문서에 있고, 학생이 넣은 코드는 보안 규칙이 견준다. 학생은 자기 팀의 입장 기록만 읽는다. **보안 규칙을 다시 배포해야 한다.**
- 예전에 인쇄한 교실 QR을 찍으면 그 미션 화면(인증코드 입력)으로 간다. 다른 교실 QR을 찍는 “잘못된 교실” 기록은 더 생기지 않는다.

### 도서관 오류찾기가 자동으로 채점되지 않음

- 해결: 부스 화면의 “문제와 정답 등록”에 정답을 넣으면 제출하는 순간 문제마다 찾기·고치기 두 항목을 따로 채점한다(40·60점, 학년당 1문제면 100점). 학생 화면에도 문제별 결과가 바로 보인다. 정답을 비운 문제가 하나라도 있으면 예전처럼 선생님이 직접 채점한다. 자동 점수는 순위표에서 고칠 수 있다.
- 2026-10-07 바꾼 것: 책 제목·쪽수 입력을 없앴다(특정 책의 쪽수를 정답으로 두는 것이 의미가 없어서). 문제는 학년별로 다르게 두며(등록 화면의 3·4·5·6학년 탭, 없는 학년은 공통 문제), 과학에 치우치지 않도록 학년마다 질문 2개(과학 + 역사·우리말·예술)를 넣고 학생이 “AI에게 한 질문” 카드 하나를 골라 그 글만 조사한다(“학생이 질문 하나만 골라 풀어요” 설정, 한 번 고르면 못 바꿈, 고른 문제로 100점). 형식은 번호가 붙은 문장 가운데 틀린 문장을 고르고 바르게 고치는 선택형이다(글에서 틀린 부분을 직접 적는 서술형도 남아 있다). 어설프게 아는 학생이 걸리도록 글에는 “맞는데 틀린 것처럼 보이는 문장”을 함께 넣는다. 학생은 참고한 책 이름도 꼭 적어 내지만 채점에는 넣지 않고 순위표에서 확인만 한다. 학생 화면과 부스 화면에 “AI가 알려 준 정보, 믿어도 될까요?” 이야기와 부정행위 경고(디벗·스마트폰·인터넷 검색 적발 시 탈락)가 나오고, 탈락은 순위표에서 점수를 0점으로 고쳐 처리한다.
- 실제 글과 정답은 행사 사이트에서 교사가 등록한다(저장소에는 샘플만 있다).

### 골든벨 정답 공개 시점과 채점

- 해결: “학생 화면에 정답 공개”는 모든 팀이 제출했거나 게임 시간이 끝난 뒤에만 켜진다(그 전에는 이유를 보여 준다). 공개하면 학생 화면에 정답과 맞힌 문제 수, 점수가 바로 보인다.
- 순위표의 확정 버튼은 “정답 공개하고 순위 확정”이 되어 한 번에 정답 공개와 순위 확정을 한다. 단답형 답을 다르게 볼 때는 확정 전에 점수를 고치거나, 확정 뒤 “순위 수정”으로 고친다.
- 문제가 바뀌지 않은 것처럼 보인 이유: 운영 사이트의 골든벨 문제는 교사 계정으로 “문제 파일 올리기”를 해야 바뀐다(코드 배포만으로는 바뀌지 않는다).

### 최종 미션 결과 발표

- 해결: 총괄이 결과를 공개하면 전자칠판 화면(학급 최종 미션)에 “결과 확인” 버튼이 나온다. 누르면 두구두구 → 1위 학급 발표(트로피·색종이·팡파르) → 전체 순위(우리 반 강조) 순서로 보여 준다. 발표를 닫으면 점수와 순위가 화면에 남는다. 총괄의 최종 미션 현황에도 “결과 발표 화면”이 있다.

### 로봇 길찾기를 도전 과제 카드 방식으로 바꿈

- 결정(사용자): 실물 도전 과제 카드(출발·도착 칸과 길 조각 개수)를 제시하고, 팀이 보드판에 길 조각을 이어 길을 완성한다. 교사가 오조봇으로 지나가 보고 성공을 판정한다. 제한 시간 7분, 난이도는 자유로 고르며 고르면 카드가 무작위로 나온다. 별 1개 5점, 2개 10점, 3개 20점.
- 준비물: 오조봇 보드판(6×6)과 길 조각을 팀 수만큼, 카드 8장(★ 4·5, ★★ 6·7·9, ★★★ 11·12·15)에 나온 조각이 모자라지 않게 준비한다.

### 카드 보상을 1~3위만 받도록 바꿈

- 결정(사용자, 2026-10-01): 1위는 3종 중 선택, 2위는 2종 중 선택, 3위는 무작위 1장, 4위부터는 카드 보상이 없다.
- 반마다 받는 카드가 줄어든다(반마다 평균: 4개 반 약 19장, 5개 반 15장, 6개 반 12.5장. 5종 완성에는 20장 이상 필요). 힌트 수와 순위 규칙(정답 수 → 5종 완성 → 시간)은 그대로다.
- 순위를 고치면 보상 없던 팀도 3위 안에 들면 보상을 받는다. 이미 받은 카드는 그대로 둔다.

## 행사 전 점검

1. 마지막 연습이 끝나면 행사 설정 → 연습 기록 지우기에서 3~6학년을 하나씩 지운다.
2. 지운 뒤 기록 수가 모두 0이고 최종 미션이 “열기 전”인지 확인한다.
3. 학생 기기는 팀 QR로 다시 입장한다(지우면 팀에 묶인 기기가 풀린다).
4. 게임 시간(행사 설정)과 진행 학년(대시보드)을 확인한다.
5. 행사 설정에서 교실 인증코드 5개가 모두 정해져 있는지, 부스 화면에 코드가 보이는지 확인한다.
6. 골든벨 부스에서 문제 파일을 올렸는지(학년별 15문항), 도서관 부스에서 학년별 문제(3·4·5·6학년 탭)와 정답을 등록했는지 확인한다.
