# 문항 작성 폴더

실제 행사에 쓸 미션 내용과 최종 미션 문제를 정리하는 곳입니다. 여기에 적은 뒤 Claude Code에 **"content/작성 폴더 내용 적용해 줘"**라고 요청하면 프로그램에 반영합니다.

## 폴더

| 위치 | 용도 |
| --- | --- |
| `content/작성/` | **여기에 입력합니다.** 정답이 들어 있으므로 GitHub에 올라가지 않습니다(`.gitignore`). |
| `content/작성/images/` | 틀린그림 찾기 그림 등 이미지 파일 |
| `content/양식/` | 빈 양식 원본입니다. 고치지 마세요. 작성 파일을 망가뜨렸을 때 다시 복사해 쓰는 용도입니다. |

`content/작성/`은 이 컴퓨터에만 있습니다. **백업은 직접** 해 주세요(학교 클라우드나 USB에 폴더째 복사).

## 파일

| 파일 | 내용 | 채점 |
| --- | --- | --- |
| `00-행사-기본정보.md` | 행사 이름, 미션 이름·교실, 시간, 학급 수 | - |
| `01-골든벨.md` | 객관식 퀴즈 | 자동 |
| `02-틀린그림찾기.md` | 그림 한 장과 정답 위치 | 자동 |
| `03-설명대로그려라.md` | 그림으로 표현할 설명 글, 채점 기준 | 선생님 |
| `04-로봇길찾기.md` | 학생 화면 규칙, 코스·점수 메모 | 선생님 |
| `05-도서관-오류찾기.md` | 틀린 내용이 든 글, 선생님용 정답 | 선생님 |
| `06-최종미션-3학년.md` ~ `6학년.md` | 학년별 4지선다 10문제 | 자동 |

## 적는 방법

1. 파일을 열고 `- 문제:`처럼 **콜론(:) 뒤에** 내용을 적습니다. 항목 이름은 지우지 마세요.
2. 쓰지 않는 칸은 비워 둡니다. 블록이 모자라면 복사해서 늘리고, 남으면 지웁니다.
3. 다 쓴 파일은 맨 위 "작성 상태"를 `[x] 작성 완료`로 바꿉니다. **완료 표시한 파일만 적용합니다.**
4. 형식이 조금 달라도 괜찮습니다. 적용할 때 제가 읽고 애매한 곳은 되물은 뒤 반영합니다.

메모장, VS Code 어느 것으로 열어도 됩니다. 한글(HWP)이나 엑셀로 정리한 자료가 이미 있으면 파일째 `content/작성/`에 넣고 알려 주세요. 제가 이 형식으로 옮겨 드립니다.

## 꼭 지킬 것

- **학생·선생님 이름, 연락처, 이메일, 사진을 적지 않습니다.** 문제 속 인물은 "민지", "로봇 가"처럼 지어낸 이름을 씁니다.
- 책·기사·그림을 길게 옮겨 적지 않습니다. 도서관 미션은 책 제목과 쪽수로 확인하게 합니다.
- AI가 만든 그림·글을 쓸 때는 만든 도구와 날짜를 적어 둡니다.
- 최종 미션 정답은 학생이 볼 수 있는 곳(학급 게시판, 공유 폴더)에 두지 않습니다.

## 학년에 맞게 쓰기

- 3~4학년: 한 문장은 짧게(15~20자 안팎), 낯선 낱말은 풀어서. 보기 길이도 짧게.
- 5~6학년: 이유를 묻는 문제, 자료를 읽고 판단하는 문제를 섞어도 좋습니다.
- 전자칠판(최종 미션)은 교실 뒤에서도 읽혀야 하므로 문제 두 줄, 보기 한 줄을 넘기지 않는 것을 권합니다.
- 보기 네 개의 길이를 비슷하게 맞추면 "가장 긴 보기가 정답" 같은 찍기를 막을 수 있습니다.

## 지금 프로그램의 한계(미리 알아 두세요)

- 미션 1~5의 내용은 **모든 학년이 같은 세트**를 씁니다. 학년별로 다르게 하려면 각 파일의 체크 칸에 표시해 주세요. 적용할 때 프로그램을 함께 고칩니다.
- 틀린그림·그리기·도서관 미션은 **내용이 하나**라서 먼저 한 팀이 뒤 팀에게 알려 줄 수 있습니다. 라운드별로 바꾸고 싶으면 체크 칸에 표시해 주세요.
- 최종 미션은 **학년별로 다른 10문제**를 쓸 수 있습니다.

## 적용을 요청하면 하는 일

1. `작성 완료` 표시한 파일을 읽고 형식을 검사합니다(보기 수, 정답 번호, 힌트가 정답을 지우지 않는지, 영역별 2문제 등).
2. 애매한 곳은 되묻습니다. 맞춤법·띄어쓰기 제안은 따로 보여 드리고 허락받은 것만 고칩니다.
3. 미션 내용은 프로그램에 넣고, **최종 미션 정답은 공개 저장소와 학생 기기에 들어가지 않는 방법**으로 넣습니다(총괄 선생님 화면에서 올리는 방식).
4. 검사를 돌리고, 어떻게 보이는지 미리보기로 확인한 뒤 알려 드립니다.
