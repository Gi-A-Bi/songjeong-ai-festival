# 문항 작성 폴더

실제 행사에 쓸 미션 내용과 최종 미션 문제를 정리하는 곳입니다. 여기에 적은 뒤 Claude Code에 **"content/작성 폴더 내용 적용해 줘"**라고 요청하면 프로그램에 반영합니다.

## 폴더

| 위치 | 용도 |
| --- | --- |
| `content/작성/` | **여기에 입력합니다.** 정답이 들어 있으므로 GitHub에 올라가지 않습니다(`.gitignore`). |
| `content/작성/images/` | 틀린그림 찾기 그림 등 이미지 파일 |
| `content/양식/` | 빈 양식 원본입니다. 고치지 마세요. 작성 파일을 망가뜨렸을 때 다시 복사해 쓰는 용도입니다. |

`content/작성/`은 이 컴퓨터에만 있습니다. **백업은 직접** 해 주세요(학교 클라우드나 USB에 폴더째 복사).

## 파일

| 파일 | 내용 | 채점 |
| --- | --- | --- |
| `00-행사-기본정보.md` | 행사 이름, 미션 이름·교실, 시간, 학급 수 | - |
| `01-골든벨.md` | 학년별 O/X·객관식·단답형 퀴즈 | 자동 |
| `02-틀린그림찾기.md` | 그림 한 장과 정답 위치 | 자동 |
| `03-설명대로그려라.md` | 학년군별 명화 그림 프롬프트(①, ②), 학년별 선택 | 선생님 |
| `04-로봇길찾기.md` | 학생 화면 규칙, 코스·점수 메모 | 선생님 |
| `05-도서관-오류찾기.md` | 틀린 내용이 든 글, 선생님용 정답 | 선생님 |
| `06-최종미션-3학년.md` ~ `6학년.md` | 학년별 4지선다 10문제 | 자동 |

## 적는 방법

1. 파일을 열고 `- 문제:`처럼 **콜론(:) 뒤에** 내용을 적습니다. 항목 이름은 지우지 마세요.
2. 쓰지 않는 칸은 비워 둡니다. 블록이 모자라면 복사해서 늘리고, 남으면 지웁니다.
3. 다 쓴 파일은 맨 위 "작성 상태"를 `[x] 작성 완료`로 바꿉니다. **완료 표시한 파일만 적용합니다.**
4. 형식이 조금 달라도 괜찮습니다. 적용할 때 제가 읽고 애매한 곳은 되물은 뒤 반영합니다.

메모장, VS Code 어느 것으로 열어도 됩니다. 한글(HWP)이나 엑셀로 정리한 자료가 이미 있으면 파일째 `content/작성/`에 넣고 알려 주세요. 제가 이 형식으로 옮겨 드립니다.

## 꼭 지킬 것

- **학생·선생님 이름, 연락처, 이메일, 사진을 적지 않습니다.** 문제 속 인물은 "민지", "로봇 가"처럼 지어낸 이름을 씁니다.
- 책·기사·그림을 길게 옮겨 적지 않습니다. 도서관 미션은 책 제목과 쪽수로 확인하게 합니다.
- AI가 만든 그림·글을 쓸 때는 만든 도구와 날짜를 적어 둡니다.
- 최종 미션 정답은 학생이 볼 수 있는 곳(학급 게시판, 공유 폴더)에 두지 않습니다.

## 학년에 맞게 쓰기

- 3~4학년: 한 문장은 짧게(15~20자 안팎), 낯선 낱말은 풀어서. 보기 길이도 짧게.
- 5~6학년: 이유를 묻는 문제, 자료를 읽고 판단하는 문제를 섞어도 좋습니다.
- 전자칠판(최종 미션)은 교실 뒤에서도 읽혀야 하므로 문제 두 줄, 보기 한 줄을 넘기지 않는 것을 권합니다.
- 보기 네 개의 길이를 비슷하게 맞추면 "가장 긴 보기가 정답" 같은 찍기를 막을 수 있습니다.

## 지금 프로그램의 한계(미리 알아 두세요)

- 골든벨은 **학년별로 다른 문제**(O/X·객관식·단답형)를 쓸 수 있습니다. 그리기는 학년군별 프롬프트를 고릅니다.
- 틀린그림·로봇 길찾기·도서관 미션의 내용은 **모든 학년이 같은 세트**를 씁니다. 학년별로 다르게 하려면 각 파일의 체크 칸에 표시해 주세요. 적용할 때 프로그램을 함께 고칩니다.
- 골든벨·틀린그림·그리기·도서관 미션은 **라운드마다 내용이 같아** 먼저 한 팀이 뒤 팀에게 알려 줄 수 있습니다. 라운드별로 바꾸고 싶으면 체크 칸에 표시해 주세요.
- 최종 미션은 **학년별로 다른 10문제**를 쓸 수 있습니다.

## 적용을 요청하면 하는 일

1. `작성 완료` 표시한 파일을 읽고 형식을 검사합니다(보기 수, 정답 번호, 힌트가 정답을 지우지 않는지, 영역별 2문제 등).
2. 애매한 곳은 되묻습니다. 맞춤법·띄어쓰기 제안은 따로 보여 드리고 허락받은 것만 고칩니다.
3. 미션 내용은 프로그램에 넣고, **최종 미션 정답은 공개 저장소와 학생 기기에 들어가지 않는 방법**으로 넣습니다(총괄 선생님 화면에서 올리는 방식).
4. 검사를 돌리고, 어떻게 보이는지 미리보기로 확인한 뒤 알려 드립니다.

## 골든벨 문제는 선생님이 직접 올릴 수 있습니다

골든벨(01 파일)도 Claude Code 없이 반영할 수 있습니다. 정답이 프로그램 코드에 들어가지 않도록 **교사 화면에서 파일을 올리는 방식**입니다.

1. `01-골든벨.md`에 `## 3학년`, `## 4학년`, `## 5·6학년`처럼 학년 제목을 달고 그 아래에 `### 문제 1`부터 적습니다. 형식은 `OX`, `객관식`, `단답형` 중 하나입니다. 다 적으면 맨 위 작성 상태를 `[x] 작성 완료`로 바꿉니다. 지금 들어 있는 원고는 「2026학년도 송정 AI 페스티벌 운영 계획(안)」의 골든벨 문항(학년별 15문항)입니다.
2. 프로젝트 폴더에서 `npm run golden:build`를 실행합니다. `골든벨-업로드.json`이 이 폴더에 만들어지고, 형식이 틀린 곳은 학년·번호와 함께 알려 줍니다. **이 파일에는 정답이 들어 있으니 다른 곳에 옮기거나 공유하지 마세요.**
3. 행사 사이트에 교사 계정으로 로그인 → 대시보드의 "1. AI 골든벨" 부스 → **문제 등록** → 맨 아래 **문제 파일 올리기**에서 그 파일을 고르고 "문제 올리기"를 누릅니다.
4. 파일에 있는 학년의 문제만 바뀝니다. 올린 뒤에도 같은 화면에서 학년을 골라 한 문제씩 고칠 수 있습니다(단답형의 "함께 인정하는 답" 포함).
5. 행사 중에 문제를 바꾸면 이미 제출한 팀의 자동 점수도 새 문제 기준으로 다시 계산됩니다. 행사 전에 미리 올려 두세요.

## 최종 미션 문제는 선생님이 직접 올릴 수 있습니다

최종 미션(06 파일)은 Claude Code 없이도 반영할 수 있습니다. 정답이 프로그램 코드에 들어가지 않도록 **총괄 선생님 화면에서 파일을 올리는 방식**입니다.

1. `06-최종미션-3학년.md` ~ `6학년.md`를 완성하고 맨 위 작성 상태를 `[x] 작성 완료`로 바꿉니다. 지금 들어 있는 원고는 2026-09-24에 전달받은 완성본입니다.
   - 문제마다 `## 문제 1. 유형 이름` 제목, `**문제 글**`, `> 제시문`(없으면 생략), `![그림 설명](images/final/파일.webp)`(없으면 생략), `① ~ ④` 보기, `- 정답: ③`, `- 힌트 사용 시 제거: ①`, `- 영역: 생각`(생각·관찰·표현·명령·검증 중 하나), `- 해설:` 순서로 적습니다. 예전 양식(`- 문제:`, `- 보기1:`)으로 적어도 됩니다.
   - `- 교사용 주의:` 줄은 프로그램에 들어가지 않고, 만들 때 화면에 알림으로만 나옵니다.
2. 그림은 `images/final/` 폴더에 **1280px 이하 WebP 또는 JPG**로 넣습니다(한 장 300KB 이하 권장, 한 학년 합계 600KB 이하). 그림 안에 보기 번호가 있으면 프로그램이 보기 순서를 섞지 않습니다. 그림에 정답 표시가 없는지 꼭 확인하세요.
3. 프로젝트 폴더에서 `npm run final:build`를 실행합니다. `최종미션-업로드.json`이 이 폴더에 만들어지고, 형식이 틀린 곳은 학년·번호와 함께 알려 줍니다. **이 파일에는 정답이 들어 있으니 다른 곳에 옮기거나 공유하지 마세요.**
4. 행사 사이트에 총괄(admin) 계정으로 로그인 → 행사 설정 → **최종 미션 문제 올리기**에서 그 파일을 고르고 "문제 올리기"를 누릅니다. 미리보기에서 문제 수·그림 수를 확인할 수 있습니다.
5. 이미 연 학년이나 시작한 반이 있는 학년은 바꿀 수 없습니다(답안이 문제 번호에 묶여 있어서). 행사 전에 미리 올리고, 담임 선생님 기기는 새로고침하면 새 문제를 씁니다.
