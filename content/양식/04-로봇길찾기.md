# 04. 로봇 길찾기 (미션 4 · 명령 카드)

오조봇 코스는 교실에서 실물로 진행합니다. 디벗에는 규칙 안내와 "준비 완료" 버튼만 나오고, 점수는 선생님이 직접 입력합니다.

- 작성 상태: [ ] 작성 중  [ ] 작성 완료(적용해도 됨)
- 마지막으로 고친 날:

## 프로그램이 받는 형식

- 학생 화면에 보여 줄 **규칙 문장 목록**(짧은 문장 3~6개).
- 점수와 순위는 선생님이 부스 화면에서 입력합니다. 계산 방법은 자유입니다(예: 완주 100점 − 재시도 1회당 10점 + 남은 시간 보너스).

## 참고: 지금 들어 있는 샘플(적용되지 않는 예시)

1. 선이 끊기지 않게 굵고 진하게 그려요.
2. 컬러 코드는 선 위에 순서대로 칠해요.
3. 출발선에 로봇을 올리고 준비되면 버튼을 눌러요.
4. 완주 시간과 재시도 횟수는 선생님이 기록해요.
